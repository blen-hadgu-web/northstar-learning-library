A curation portal for accessible technology-learning resources

Northstar Learning Library will help learners search, filter, compare, and save trustworthy resources for web development, accessibility, and computer science.

Project blueprint

Curation & Discovery Portal

Planned application structure

  • A top search header for finding learning resources.
  • A filter sidebar for topic, level, format, and accessibility features.
  • A responsive card-grid gallery for curated resources.
  • A comparison area for evaluating selected learning materials.
